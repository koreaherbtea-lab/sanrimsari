승인된 회원 목록

ℹ️ '탈퇴 처리'를 누르면 이 사이트의 회원 정보(신청 기록)만 삭제되고, 이메일 주소가 클립보드에 복사됩니다. 그 이메일로 Firebase 콘솔 → Authentication에서 로그인 계정 자체도 삭제해야 완전히 탈퇴 처리됩니다 (그래야 재로그인/재가입이 불가능해집니다).
✅ 사이트 내 탈퇴 처리 완료 — 아래 순서로 로그인 계정도 마저 삭제해주세요 ×
  1. 아래 이메일 주소를 복사(자동으로 이미 클립보드에 복사됨)
  2. Firebase 콘솔 접속 → Authentication → 상단 "사용자" 탭 이동
  3. 검색창 클릭 → Ctrl+V(붙여넣기)로 이메일 검색
  4. 해당 계정 오른쪽 점 3개(⋮) 메뉴 → "계정 삭제" 클릭
